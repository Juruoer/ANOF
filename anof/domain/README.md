# 领域模型

领域层描述 ANOF 中的账户、空间、文件和维护记录，以及这些数据必须遵守的规则。例如一次文件复制应增加多少逻辑用量、一棵目录树是否形成环，都可以在这里检查，而不需要打开数据库。

| 目录                                 | 主要内容                               |
|--------------------------------------|----------------------------------------|
| [identity](identity/README.md)       | 用户、会话、邀请和秘密值               |
| [drive](drive/README.md)             | 文件树、空间、额度、回收站和内容状态   |
| [transfer](transfer/README.md)       | 上传记录、偏移、状态变化和存储预算     |
| [maintenance](maintenance/README.md) | 检查结果、修复计划、动作证据和备份清单 |

这些代码编入 `anof_domain`
，不执行网络、数据库或文件操作。应用层先取得需要的数据，调用领域规则，再通过仓储保存结果。因此，领域校验通过后，应用仍要处理权限、并发修改和事务提交，详见 [application](../application/README.md)。

修改规则时可以先看相应子目录的测试；跨实体事务和恢复行为在[根测试目录](../../tests/README.md)验证。
