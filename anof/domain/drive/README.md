# 云盘领域值与策略

本目录不依赖 HTTP、数据库或文件系统。[TreePolicy.h](TreePolicy.h) 和 [DrivePolicy.cc](DrivePolicy.cc)
提供完整有界树的拓扑、归属、逻辑计费与目标深度校验。重复 ID、断链、环、跨空间树及文件拥有子节点被拒绝；
整树上限1000，活动节点深度上限128。共享内容按每个文件节点计逻辑字节，并按 createdBy 聚合。

SearchText 校验1..128字节UTF-8和控制字符，保留空格、大小写及通配符的字面值；不执行查询。
QueryBudget只允许缩短100ms、10000000指令和100000候选的上限。数据库适配器负责实际执行预算。

[Trash.h](Trash.h) 定义条目、条件及30天保留时间；[Blob.h](Blob.h) 将不可变内容描述与持久生命周期记录分开，
提供24小时宽限及删除状态校验。GC候选判断接收真实引用状态，但不提供磁盘删除资格。
[NodeAccounting.h](NodeAccounting.h) 保证 used+reserved 不超过100000；预留、发布与释放均为不修改输入的
受检纯计算，零变化不推进版本，溢出或下溢失败。额度释放与物理占用释放分别计算，不混淆两个账本。

[领域测试](tests/DrivePolicy_unittest.cc) 覆盖树权限、1000/1001及深度边界、共享内容计费、保留期/回拨、节点
计数和上传删除证据。纯值测试不证明数据库事务、GC互斥或进程恢复；本目录不提供用例服务。
