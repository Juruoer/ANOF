# 应用公共端口

这里定义应用与存储、密码处理、调度和实例维护之间的类型化 C++ 接口。业务传递领域值，不传 SQL、SQLite 句柄、HTTP 或 JSON 对象。具体实现位于 infrastructure 和 runtime。

以创建目录为例：应用通过 Store 打开事务，从事务取得授权、节点和额度仓储，再将目录与审计一起提交。具体 SQLite 适配器实现这些接口，应用不需要了解连接句柄或 SQL。

## 端口分组

- 元数据：只读快照、共享事务、账户/目录/传输仓储及审计。
- 身份：密码哈希、令牌摘要、ID 生成和请求身份。
- 调度：任务接纳、取消、完成回调及上传/下载流。
- 实例维护：初始化、检查、修复、备份快照、文件证据和离线锁。

读写对象与返回的仓储引用有明确借用期；相关写入和审计必须共享事务。未知提交不能当作回滚，数据库事务也不能保证文件操作原子性。调度取消与底层工作结束是不同事件。

逐接口的所有权、原子性、错误和恢复要求见 [端口契约](CONTRACTS.md)。增加后端时需满足[共享后端测试](../../../tests/persistence_contract/CMakeLists.txt)，不能只以编译通过证明语义兼容。上层用例导航见 [application](../README.md)。
