# 应用用例

应用层负责把一次业务操作做完整。例如创建目录时，它要检查身份与父目录、计算额度变化，再将目录、用量和审计一起提交。它通过类型化端口访问外部资源，不直接编写 SQL 或解析 HTTP。

| 目录 | 用例 |
| --- | --- |
| [identity](identity/README.md) | 登录、注册、账户与额度管理 |
| [drive](drive/README.md) | 创建目录、移动、复制、回收站和内容清理 |
| [transfer](transfer/README.md) | 上传、下载准备与存储核对 |
| [maintenance](maintenance/README.md) | 初始化、检查、修复、备份与恢复 |
| [ports](ports/README.md) | 用例依赖的仓储、文件、密码和调度接口 |

普通元数据用例在短事务中完成；登录和上传则需要多个阶段。登录先读取密码资料，关闭快照后计算密码，最后重新检查身份并提交。上传也在文件操作前结束数据库事务。这样既不会长时间占用数据库事务，也能在提交时发现中途发生的账户或目标变化。

用例本身不创建工作线程，调用与排队由 [runtime](../runtime/README.md) 安排。HTTP 层只负责将请求转换为命令、将结果转换为响应。增加用例时，先读对应服务和[端口契约](ports/CONTRACTS.md)，尤其要明确提交失败后是否还能确定操作结果。
